用量中心现已支持 GPT-6.2 Astra、GPT-6.2 Sol，并补齐 GPT-6.1 Terra 的价格。本次也修复了多机器上的任务残留和会话恢复后的 Token 统计。

- 周限估算按模型和实际速度计算。两款 GPT-6.2 的订阅额度按 Fast 2 倍、Ultrafast 6 倍折算，缺少速度记录时按当时的订阅档位估算范围
- 在用量中心展开模型，可以查看每百万 Token 的输入、输出、缓存读取和写入单价。API Ultrafast 的限时优惠按估值区间展示
- 关闭、归档或回退 Codex 会话后，任务面板及时移除旧任务，并继续显示仍在运行的子任务。恢复会话后，Token 归到对应轮次
- 单个会话的模型提供方配置异常时，同机其他任务仍可实时更新。后台尚未启动时，设备状态会说明原因
- 修正通知投递和防睡眠重试，统一 Codex 与 Claude 的额度条配色，菜单和侧面板遵循动画开关。“设置 → 关于”可离线查看开源许可

已有用户可在“设置 → 关于”中检查更新。首次安装可下载 DMG，将 CodexBar 拖入“应用程序”。同一个安装包支持 Apple 芯片和 Intel。此包使用开发签名，若 macOS 首次打开时提示无法验证，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。

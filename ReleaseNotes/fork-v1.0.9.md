Codex 改用各机器自己的共享后台，完善实时任务、断线恢复和订阅价值估算，保留 Claude 本地采集与多机器统计。

- 本机与 SSH 来源连接各自的官方共享后台，CodexBar 不再额外运行独立 Codex 后台；重连和退出不结束用户任务
- 任务显示执行阶段、工具、计划进度和子 Agent 数量；等待子任务或异步提问保持运行，明确阻塞的提问和审批才进入等待
- 各机器、Codex 与 Claude 独立处理连接状态；恢复时不重复通知旧任务，短暂失联不会解除已有异常任务保护，并修复时间边界下偶发漏发新通知的问题
- 新增 Codex 服务状态，关于页区分后台实际版本与磁盘 CLI 版本；改进已下载更新的安装重试、单实例防护、音效分组和快捷键保存
- 日志高亮与排版移到后台，限制超大日志；保留固定顶部的窗口伸缩和简约任务动效
- 改进防睡眠恢复、自动重置的取消与重试预算，沿用现有 Helper 身份和授权
- 修复短暂旧额度回执导致整期停留在“额度参考”的问题；两分钟内恢复到原值的低值段会排除，持续或未恢复的下降仍保留保护
- 修复旧 Claude 会话缓存覆盖已重置额度，以及失效日志链接被误报为读取失败的问题

Codex 采集要求共享后台实际版本为 `0.162.0` 或更新版本。已接入的来源会更新监听器，并在确认正常后仅撤除本程序的旧 Codex Hook。Claude 仍只读取本地数据，不主动访问 Anthropic。原始日志、用量与价值账本、设置和后台授权均保留，无需重建数据库；旧周期估算会随刷新重新计算。

同一个安装包支持 Apple 芯片和 Intel，沿用开发签名，未经过 Apple 公证。首次安装将 `CodexBar.app` 拖入 `/Applications`；如被系统阻止，在“系统设置 > 隐私与安全性”中选择“仍要打开”。

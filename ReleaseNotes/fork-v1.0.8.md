官方用量明细延迟时，可用同账号设备日志估算订阅价值；同时改进任务历史回补，并增加 Codex 额度刷新间隔设置。

- 订阅价值优先采用完整的官方明细，缺失时使用本机和 SSH 设备的同账号 OAuth 日志估算；官方数据补齐后自动切回，不重复计入
- 设备日志估算区分模型、输入、输出、缓存和会话中途的 Fast 切换，排除 API 用量并跨设备去重；速度信息缺失时显示估算范围
- 修复大日志或启动回放时任务结束状态、Token 明细遗漏的问题，本机和远程任务均可回补；补回历史完成记录时不重复通知或触发流光
- 设置中新增 Codex 额度刷新间隔，可选 1、2、3、5、10 分钟，默认 1 分钟；设备同步独立运行，继续遵守现有睡眠暂停规则
- 调整套餐配色、额度受限提示和下拉栏布局，保留本 fork 的 Claude 支持、多机器统计及简约任务动效

Claude 仍只读取本地数据，不主动访问 Anthropic。已有设置、后台授权和历史统计继续保留，无需重建数据库。远程任务回补需要新版采集器，已接入的 SSH 来源可在用量中心重新接入实时任务，更新脚本。

同一个安装包支持 Apple 芯片和 Intel，沿用开发签名，未经过 Apple 公证。首次安装将 `CodexBar.app` 拖入 `/Applications`；如被系统阻止，在“系统设置 > 隐私与安全性”中选择“仍要打开”。已有用户可通过应用内检查更新升级。

## 本分支的取舍

用户确认 Codex 统一要求共享后台实际版本 `0.162.0+`。每台机器连接自己的官方 daemon，再通过既有 SSH 通道向 Mac 回传统计元数据。旧 CLI 不维持第二套实时 Hook 路径，已有历史仍可查看。

保留 Claude 纯本地采集、多机器汇总、OAuth/API 记录归属、请求级 Token 账本、Fast 和周期价值估算、现有睡眠门禁。旧 Hook schema `9`、异常保护 schema `1`、Helper 身份和授权保持。未引入 iCloud、独立 Helper 管理 App、上游发布配置或卸载历史重建方案。

## 验证范围

协议测试使用本机临时 Unix socket 和合成帧，不启动真实模型、不消费重置卡。重点覆盖分片、控制帧、断线、超时、取消、待回应匹配、子任务归属、审核代理排除、事件幂等、账号切换和历史保留。

真实机器验证覆盖本机和三台 SSH 来源的后台版本、监听器健康、任务合并及原统计库身份。原有旧 CLI 来源已按授权升级到 `0.163.0`；四台实际 daemon 都为 `0.163.0`。监听器可独立停止、恢复，不终止官方 daemon。

硬件合盖、DarkWake、首次系统授权和真实重置卡消费不通过自动测试强行触发；睡眠门禁、租约恢复和自动重置截止逻辑使用隔离回归验证。

本轮自动验证通过 `319` 项 Swift 测试、`126` 项原用量采集回归、`54` 项共享采集回归，以及既有多机器 smoke 流程。Helper 隔离状态机测试为 `17` 项。Release 主程序和 Helper 均已构建 `arm64`、`x86_64`，开发签名和打包资源校验通过。

# 主面板与菜单栏

简体中文 | [English](../en/UserGuide/main-panel.md)

## 菜单栏图标

CodexBar 用图标、状态点和可选额度条同时表达账户、任务和额度状态：

| 外观 | 含义 |
| --- | --- |
| 正常账户图标 | 账户数据可用 |
| 错误账户图标 | 未登录、初始化失败或缺少可信额度与用量数据 |
| 蓝色状态点 | 至少有一个任务正在运行 |
| 橙色状态点 | 至少有一个任务正在等待用户批准 |
| 绿色状态点 | 任务刚刚完成，高亮持续 30 秒 |
| 图标旁额度条 | 所选额度窗口的剩余比例 |

多个状态同时存在时，等待批准优先于运行中，运行中优先于最近完成。

鼠标悬停在菜单栏图标上可以查看当前任务状态、项目名、持续时间、并发任务数量和额度窗口剩余比例。

额度数据来自缓存时，图标和进度条会降低透明度，表示当前看到的不是最新快照。

## 全部、Codex 与 Claude

顶部标签切换统计范围。`全部` 依次显示 Codex 和 Claude 额度、合并热力图与设备摘要；单提供商标签只显示相应数据。Claude 额度取同账号设备中最新的可用被动记录，可能有延迟，缺失不等于零用量。

设备摘要默认折叠，点击标题栏可展开，刷新和 `用量详情` 按钮始终可用。热力图悬浮详情会区分已记录的指标与缺失字段，Claude 不会套用 Codex 的专属事件定义。用量中心的筛选不改变菜单栏范围，具体口径见 [多机器用量中心](usage-center.md)

## 自定义布局

在 `设置 > 通用 > 主面板布局` 中调整区域顺序和显隐，支持撤销与重做。具体操作见 [设置参考](settings.md#主面板布局)

## 账户区域

- 展示当前登录账户或账户类型
- 展示 Enterprise, Team, Business, Pro, Plus, Edu 和 Free 等套餐标识
- 双击账户图标会立即刷新账户、额度和用量
- 双击邮箱会切换模糊显示
- 未登录时显示 `未登录`
- 当前 Codex 版本低于要求时显示最低版本提示
- Codex 连接无法初始化时显示 `初始化失败`

具体连接失败原因可在设置的关于页面查看，完整请求和响应可在日志窗口查看。

## 额度区域

CodexBar 会展示 Codex 返回的全部额度分组和窗口。

每个额度窗口包含以下信息：

- 窗口名称，例如 `5h` 或 `7d`
- 剩余比例
- 分段进度条
- 下一次重置时间

开启 `动画效果` 时，Codex 和 Claude 的额度条会在打开主面板及切换标签时重新填充到当前剩余比例。

主额度分组还可能展示以下信息：

- 可用积分或无限积分状态
- 可用留存重置
- 每批留存重置的过期时间

点击 `留存重置` 可查看各批次的过期时间，入口只在可用次数大于 `0` 时显示。

## Token 用量与热力图

汇总区域会展示以下指标：

- 全时累计 Token
- 单日 Token 峰值
- 当前连续使用天数
- 最长连续使用天数
- 最长任务时长

热力图使用 30 列乘 7 行方块展示近 30 周每日 Token 用量，颜色强度相对于当前热力图中的峰值计算。

开启 `动画效果` 时，日期方块会在每次打开主面板时从左上到右下依次展示。

悬停日期方块时会显示日期、Token 数量和用量强度。

本机 Codex 优先显示可用的 Hook 统计；设备日志提供相应记录时也可补充日期详情。可能显示的指标包括：

- 最常用模型
- 会话数
- 对话轮次
- 子 Agent 数
- 工具调用次数
- 权限请求次数
- 上下文压缩次数

## 活动卡片

活动卡片的状态优先级为等待批准、运行中、最近完成、最近终止。

卡片会按实际可用字段展示以下内容：

- 项目名
- 模型和推理强度
- 当前工具或执行阶段
- 已运行或已等待时间
- 活跃子 Agent 数
- 其他并发任务数
- 匿名任务图标

防睡眠实际生效时，活动卡片右侧会显示咖啡杯标记。

无法识别会话的任务带有橙色匿名图标，悬停显示 `匿名任务不参与防睡眠`

活动卡片的 `+N` 表示其他活跃任务总数。

点击有内容的活动卡片可以打开任务中心。

## 任务中心

任务中心按状态分组展示以下内容：

- 等待确认
- 运行中
- 最近完成
- 最近终止

最近完成和最近终止记录保留 10 分钟。完成表示一轮任务结束；终止表示被中断，不触发完成通知。

完成不代表结果一定成功。

## 底部状态

主面板底部包含以下信息：

- 数据更新时间
- 距离下一次自动刷新的倒计时
- iCloud 同步关闭、同步中、已同步或失败状态
- 可用更新提示

发现新版本时，双击更新提示可以开始更新。

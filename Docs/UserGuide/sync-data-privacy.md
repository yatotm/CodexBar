# 数据、同步与隐私

简体中文 | [English](../en/UserGuide/sync-data-privacy.md)

## 多机器统计

本 fork 已移除 iCloud/CloudKit。菜单栏和设置页不再提供 iCloud 开关或同步状态，App 不再访问原云端容器。以前的云端数据、旧缓存和偏好不主动删除，当前版本不再使用它们。

Mac 与 VPS 的统计通过用量中心的 SSH/HTTPS 来源合并，与 iCloud 无关。部署和账号归属见 [多机器用量中心](usage-center.md) 与 [Linux 采集端](../../Collector/README.md)

## 哪些数据会传输

采集器在日志所在设备解析，只传输经过筛选的时间、模型、Token、事件计数、额度观察和哈希身份。项目显示名也会进入统计协议。对话正文、工具参数、工具输出、完整工作目录和登录 Token 不进入导出数据。

Claude 只读取客户端已经留下的日志和缓存，不主动请求 Anthropic。Codex 官网分析使用本机已有的 OAuth，只向官方主机发出只读请求，不读取浏览器 Cookie，不自行续期或改写登录凭据。

## 本机数据

| 数据 | 保存方式 |
| --- | --- |
| Hook 原始事件与日聚合 | 保留 210 天；日聚合中的会话和轮次身份明细仅保留最近 3 天 |
| 用量中心 | 本机 SQLite 保存来源、经筛选的事件、Token 和额度记录 |
| 官网分析与周限历史 | 按账号隔离的缓存 |
| 异常会话保护 | 哈希任务身份和时间，最长保留到最后进展后 24 小时 |
| App 设置 | 当前 Mac 的偏好域，包含代理配置；代理密码以明文保存 |
| HTTPS 统计服务令牌 | 本机钥匙串 |
| 交互日志 | 最近 500 条 app-server 请求与响应，只存在本次运行的内存中 |

本机数据位于 `~/Library/Application Support/CodexBar-yatotm`。首次迁移保留旧文件，具体步骤见 [迁移说明](migration.md)

## 重建数据

在 `设置 > 高级 > 重建数据` 选择日期范围，使用保留的本机 Hook 原始记录重新计算统计。可选最近 210 天，不删除原始记录，也不修改用量中心数据库、账号额度或远端设备的数据。

## 网络与日志

| 访问目标 | 用途 |
| --- | --- |
| 本机 Codex app-server | 读取账号、额度、用量和重置券；实际联网由 Codex 处理 |
| 官方 `chatgpt.com` | 只读账号分析与额度核对 |
| 已配置的 SSH/HTTPS 来源 | 读取统计元数据 |
| 本 fork 的 GitHub 更新源 | 检查及下载更新 |

代理设置只影响 CodexBar 启动的 Codex 服务，不修改系统网络或其他应用。分享交互日志前应检查账户和协议内容；日志不是对外发布用的脱敏摘要。

普通网页 Chat 对话不属于这里的 Codex 日志统计，美元估算也不是账单。

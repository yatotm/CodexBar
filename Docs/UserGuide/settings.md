# 设置参考

简体中文 | [English](../en/UserGuide/settings.md)

右键或 Control 点击菜单栏图标并选择 `设置`，或按 `⌘,` 打开设置窗口。

## 通用设置

| 设置 | 作用 | 默认或初始状态 |
| --- | --- | --- |
| 主面板布局 | 调整账户、任务、额度、用量、更新时间和 Codex 服务状态 | 默认显示；任务需有已配置来源 |
| 动画效果 | 控制额度条、热力图和任务图标的轻量提示 | 开启 |
| 开机自动启动 | 登录 Mac 后启动 CodexBar | 跟随系统登录项状态 |
| 自动检查更新 | 检查本 fork 的更新，Debug 构建不启用 | 跟随当前更新设置 |
| 菜单栏额度指示 | 显示 Codex 七天额度的剩余比例 | 7d |
| 全局快捷键 | 在任意 App 中开关主面板 | `⌘⇧W` |

开机启动等待系统批准时，设置会显示授权提示；点击 `打开系统设置` 后自行允许，返回 App 即刷新状态。

### 主面板布局

点击右侧选项按钮后，可拖动排序或切换区域开关，至少保留一个区域。使用 `⌘Z` 撤销、`⌘⇧Z` 重做。隐藏区域通常不影响采集；官方服务状态只在对应区域和面板可见时查询。

任务开关依据已配置的共享后台、Claude 或远端来源，临时断线不会改写布局。没有任务来源时隐藏任务区域；若任务原本是唯一可见区域，自动保留账户区域。

### 任务流光

在 `设置 > 通用` 开启后，各显示器顶部以光带提示任务状态，首次开启播放一次预览。默认关闭，覆盖本机及已接入开发机的 Codex、Claude，不随主面板标签筛选；至少需要一个可用任务来源。

开启后点击右侧选项按钮，可调整：

| 选项 | 默认值 | 可选值 |
| --- | --- | --- |
| 运行、等待、完成、终止颜色 | 青、橙、绿、红 | 六位 Display P3 十六进制颜色；留空恢复默认 |
| 动画速度 | 标准 | 较慢、标准、较快 |
| 亮度 | 100% | 20%～100% |
| 结束时长 | 10 秒 | 3, 5, 10, 15, 30, 60 秒 |

仍有其他任务运行时，结束提示显示 3 秒后恢复当前状态；全部任务结束后，按所选时长显示，从实际结束时间起算。它不改变任务历史、通知或防睡眠设置。双击颜色块可预览对应状态；关闭外观面板后恢复实际状态，预览期间暂停真实结束提示的倒计时。

睡眠、屏幕熄灭或用户会话切换时撤下光带。恢复连接不播放历史结束提示，延长时长也不会重新播放已经过期的提示。颜色输入结束时校验并保存；无效值恢复默认，开关关闭时保留外观设置。

### 菜单栏额度指示

固定显示 Codex 的 `7d` 剩余额度，只保留显示开关。七天窗口尚未返回时不显示额度条；数据变淡表示使用缓存额度。

### 全局快捷键

快捷键至少需要两个修饰键，不能使用 `Command-Space` 或 `Command-Tab`。组合已被占用时会提示冲突。可以清除快捷键或恢复默认值。

## 高级设置

| 设置 | 作用 | 默认状态 |
| --- | --- | --- |
| Codex 共享后台 | 复用本机官方后台，要求 `0.162.0+` | 自动连接 |
| Codex 额度刷新 | 选择 1、2、3、5 或 10 分钟更新一次账户额度 | 1 分钟 |
| [系统通知](notifications.md) | 配置通知类型、阈值、音效和触觉反馈 | 总开关关闭 |
| 自动重置 | 提前使用即将过期的留存重置 | 关闭，提前 30 分钟 |
| [防止系统睡眠](sleep-prevention.md) | 选择关闭、手动保持唤醒或跟随本机 Codex 任务 | 关闭 |
| [重建数据](sync-data-privacy.md#重建数据) | 重新计算所选日期的 Hook 统计 | 手动操作 |

### 代理

连接与代理配置沿用官方 Codex 后台，不再提供 App 专用代理开关。需要调整时，在 Codex 自身配置中处理；CodexBar 不会替换运行中的后台。旧版保存的代理设置保留供回退，新链路不读取它们。

### Codex 额度刷新

修改间隔会重排下一次轮询，不中断正在进行的请求。设备日志、实时任务、价值统计及旧历史维护保留各自节奏。可见的官方服务状态随额度刷新，不另设轮询。合盖暂停、外接显示器继续工作和睡眠恢复规则不变。

### 自动重置

自动重置会在留存重置即将过期时自动使用它。每次开启均需确认；如提示后台服务需要授权，点击设置行下方的 `打开系统设置` 并允许 CodexBar 后台运行。

开启且 CodexBarHelper 获得批准后，点击右侧选项按钮设置临期时间：`15 分钟`、`30 分钟`、`1 小时`、`2 小时`、`4 小时` 或 `6 小时`，默认提前 `30 分钟`。

- 优先处理最早到期的可用留存重置，使用前重新检查登录和可用状态
- 可能短暂唤醒 Mac，但不点亮屏幕，也不会打开防睡眠开关
- 暂时失败时自动重试，每轮最多持续 5 分钟；后续刷新仍可再次尝试
- Mac 唤醒或 App 重新启动后，会补查尚未过期的留存重置
- 关闭功能或退出 App 会取消已安排的唤醒
- 多台 Mac 同时开启时，同一留存重置不会因重复尝试而多次消费

自动重置不依赖通知开关。结果提醒可在 [通知选项](notifications.md#自动重置通知) 中配置。该功能的设置只保存在当前 Mac。

## 关于页面

| 项目 | 操作或含义 |
| --- | --- |
| 来源 | 仅用于启动尚未运行的后台，自动模式优先全局 CLI，再尝试 App 内置版本 |
| 重新建立连接 | 只重连 CodexBar 客户端，不重启后台或其他任务 |
| 共享后台 | 显示握手版本与连接状态，点击 socket 路径复制 |
| Codex CLI / Codex App | 分别显示磁盘上的安装版本，点击路径复制 |
| CodexBar 版本 / 检查更新 | 查看版本、检查更新，已下载时可直接安装并重启 |
| 更新日志 | 打开当前 fork 版本对应的 Release 页面 |
| OpenAI 服务状态 | 打开官方公开状态页 |
| GitHub 项目 | 打开 `yatotm/CodexBar` |
| 退出 CodexBar | 退出 App |

连接期间暂时不能切换来源。连接失败原因显示在版本区域底部，可据此排查或重新选择来源。

## 用量中心设置

菜单栏的 `用量详情` 打开独立窗口，在这里管理来源、刷新间隔、统计范围和历史账号归属。Codex 当前登录方式会自动检测，无法确认的历史记录保留为未知；同账号周限来源需要自行确认。远端采集由该设备自己的服务管理；本机通知和防睡眠设置不会停止远端任务。

来源配置与额度参考说明见 [多机器用量中心](usage-center.md)

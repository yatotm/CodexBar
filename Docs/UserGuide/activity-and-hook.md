# 实时任务与采集

简体中文 | [English](../en/UserGuide/activity-and-hook.md)

Codex 任务来自每台机器自己的官方共享后台；本机、SSH 设备和 Claude 合并到原有任务卡片。Claude 继续使用本地日志和被动 Hook，不主动请求 Anthropic。按任务防睡眠仍只跟随本机 Codex。

## 接入方法

1. 本机安装并登录 Codex，确认 `设置 > 关于` 的共享后台已连接且版本不低于 `0.162.0`
2. 在 `设置 > 通用 > 主面板布局` 显示 `任务`
3. 远端 Codex 和 Claude 在用量中心对应来源的 `实时任务` 中接入

不再需要开启 CodexBar 的 Codex Hook。每台远端机器独立保存采集结果，Mac 通过 SSH 同步；Mac 合盖或断网后，远端采集继续运行。配置方法见 [多机器用量中心](usage-center.md#实时任务)

CodexBar 只断开自己的后台连接，不会退出共享服务或中断其他 Codex 会话。

## 任务状态

| 状态 | 含义 |
| --- | --- |
| 运行中 | 正在思考、回复、执行工具或等待子 Agent |
| 等待回应 | 存在尚未处理的批准或提问 |
| 最近完成 | 一轮任务已结束，不代表结果一定成功 |
| 最近终止 | 任务被中断或失败，不发送完成通知 |

子 Agent 合并到所属任务；主回复结束后子任务仍在运行时，不提前显示整组完成。后台提问和阻塞提问分别处理，不把单纯等待子 Agent 当作等待批准。

有可用字段时，状态行补充计划进度、待回应数和子任务数；悬停查看完整状态及最近事件。模型、思考深度和机器按固定顺序显示。

匿名任务可以查看，但不触发通知或触觉反馈，也不参与防睡眠和异常会话保护。恢复连接时先对账当前状态，不重播旧完成通知。

长时间没有进展的本机运行任务可能被 [异常会话保护](sleep-prevention.md#异常会话保护) 隐藏，恢复进展后重新显示。

## 每日统计

悬停热力图日期，可查看日志与采集器实际记录的会话、轮次、工具调用、权限请求、上下文压缩、子 Agent 和主要模型。缺少字段保持未知，不填成零。

会话和轮次按天去重，跨天活动计入对应日期。任务快照与历史用量分别保存，不把实时累计 Token 重复加入用量账本。

## 旧 Hook 记录

已有 Hook 原始事件、日聚合、用量中心数据库和价值账本保留，不要求卸载或清空历史。`重建数据` 仍可重算保留期内的旧 Hook 原始记录；它不重建远端数据库或修改账号额度。

Claude 的 Hook 仍用于被动采集，用户和其他 App 的回调保持不变。详细保存期限和同步范围见 [数据、同步与隐私](sync-data-privacy.md)

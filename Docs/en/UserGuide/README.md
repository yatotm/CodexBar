## Common Names

- Codex shared service: the official service on each machine, providing accounts, quotas, and live tasks
- Claude Hooks: passive task observations; legacy Codex Hook history remains available
- CodexBarHelper: the included background service for sleep prevention and Automatic Reset wakes
